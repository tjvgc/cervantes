# Presentación: Miguel de Cervantes - Vida y Obra

Presentación interactiva moderna sobre la vida y obra de Miguel de Cervantes Saavedra.

## ⌨️ Controles de la Presentación

- **← →** (Flechas): Navegar entre diapositivas
- **Espacio**: Reproducir/Pausar audio
- **Clic en botones**: "Anterior" y "Siguiente"
- **Swipe** (móvil): Deslizar para cambiar de diapositiva
- **Puntos indicadores**: Clic para ir a una diapositiva específica

## 🎨 Características

✅ Diseño moderno y responsivo
✅ 10 diapositivas completas
✅ Integración con audio
✅ Enlaces a videos de YouTube
✅ Enlaces a recursos externos
✅ Navegación con teclado y táctil
✅ Indicadores de progreso
✅ Optimizado para móviles
